# Privacy Policy for homelab-backup

Last updated: 2026-10-03

homelab-backup is a personal backup tool. It is used only by its owner
to store backups of their own home server in their own Google Drive.

## Data the app accesses

The app uses the Google Drive API only to upload, list and delete
backup archives in one dedicated folder of the owner's Google Drive.
It does not read, modify or delete any other files.

## How data is used and stored

All archives are encrypted on the owner's server before upload.
Google stores only encrypted files. The app collects no analytics.
It does not share data with anyone or transfer it to third parties.

## Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.
